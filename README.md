# Zernio Clinic OS

An AI-powered operating system for aesthetic and dermatology clinics.

## Vision

Build one intelligent platform to manage every patient interaction from the first message to years of follow-up.

## Modules

- Customer CRM
- Appointments
- Treatments
- Payments
- Marketing
- WhatsApp
- Instagram
- TikTok
- Google
- AI Assistant
- Analytics

## Tech Stack

- Supabase
- PostgreSQL
- GitHub
- Next.js
- OpenAI
